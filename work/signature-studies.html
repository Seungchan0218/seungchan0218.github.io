Signature Studies

Path geometry and numerical experiments within Quant Lab.

Focus
Path signatures
Tools
Python · NumPy
Context
Part of Quant Lab

Overview

Two paths can share endpoints while taking different routes. Truncated path signatures provide structured features of those routes, including interactions that depend on the order of movement.

This exploration implements exact level-two signatures for piecewise-linear paths and applies them to causal rolling windows and path prefixes.

Components

  • A native NumPy implementation using Chen’s identity to combine path segments.
  • Forecasting comparisons between ordinary features, signature features, and their combination.
  • Simulated hedging policies comparing state information with signature-conditioned information.
  • Independent accounting checks and separate evaluations within each experiment.

Implementation and comparisons

The native signature and hedge modules work without optional PyTorch or iisignature packages. Optional adapters support upstream comparisons, while controlled experiments preserve shared conditions within an engine.

Different engines can use different normalization, objectives, and training budgets. Raw losses across those engines are not treated as directly comparable.

Scope and limitations

Hedging experiments use simulated paths. They do not establish real-market profitability, and no live orders are placed.
